FERRAMENTAS PARA DESENVOLVEDORES

Do primeiro comando à publicação

O ecossistema GBIT apoia diferentes etapas do ciclo de desenvolvimento.

Criar projetos

create-gbit-app inicia projetos com Vite, React e TypeScript; gbit-next apoia projetos Next.js.

Clonar e iniciar

gbit-start automatiza clonagem de repositórios, instalação de dependências e inicialização.

Documentar

gbit-readme auxilia na criação de documentação README para projetos.

Explorar Web3

gbit-address gera carteiras Ethereum de teste com endereço e chave privada.

Trabalhar com dados

gbit-db-dados oferece armazenamento local orientado a arquivos por CLI ou biblioteca Node.js.

Desenvolver e publicar

GBit Shell reúne comandos de terminal e fluxos Git/GitHub para apoiar o trabalho diário.
