03 / Do portfólio para seu terminal

Não fique só na apresentação.
Experimente as ferramentas.

Comandos para executar na sua máquina. Sem demos que simulam funcionalidades inexistentes.

Dentro do VS Code

Instale as duas extensões oficiais diretamente pelo editor ou pela linha de comando. 

code --install-extension gislaine.gbit-shell-terminal
code --install-extension gislaine-web3.gitml

GBit Shell + GitHub

Para enviar ao repositório existente: autentique sua conta, salve as alterações e use o endereço real do projeto. 

gh auth login
ghpush --remote https://github.com/seu-usuario/seu-repo.git -m "docs: atualiza portfolio"

Construir com GITML

Instale o CLI, confira o arquivo e gere a página a partir da fonte. 

npm install -g gitml
gitml check index.gitml
gitml build index.gitml

Começar um projeto

Explore as ferramentas do ecossistema. Revise os comandos e a documentação antes de executá-los. 

npx create-gbit-app meu-projeto
npx gbit-address

Carteiras e chaves geradas para testes não devem ser utilizadas para guardar fundos reais.
